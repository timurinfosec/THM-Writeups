# THM Pentesting Writeups

A collection of practical penetration testing writeups documenting my journey through **TryHackMe**.

This repository contains technical reports, methodologies, enumeration results, vulnerability analysis, and lessons learned from completing different machines.

## Repository Structure

| Directory | Description |
|---|---|
| `Easy/` | Easy-difficulty machine writeups |

| `Hard/` | Hard-difficulty machine writeups |
